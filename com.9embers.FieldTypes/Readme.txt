When installing the 9 Embers field types, be sure to do the following:

- Install the \Scripts\com_9embers\signature_pad.min.js file
- Delete the \bin\rocks.pillars.SignatureFieldType.dll
- If client has existing version of rocks.pillars.FieldTypes.dll, make sure to replace it with new copy from this solution (without fieldtypes that have been moved to 9 embers)
